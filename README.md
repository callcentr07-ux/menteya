# Ментея — прототип сайта клиники

Частная психиатрическая клиника, дизайн v3 «ночная вода»: стеклянный мозг на WebGL, живая карта состояний, галерея клиники, мастер «Подобрать специалиста».

## Посмотреть
- Онлайн: `https://<логин>.github.io/<репозиторий>/design-v3/` — после включения GitHub Pages (Settings → Pages → Deploy from a branch → ветка, папка `/ (root)`).
- Локально: открыть `design-v3/index.html` в Chrome, Edge или Safari. Интернет нужен только для шрифтов.
- Кнопка «Отключить анимацию» в подвале выключает всё движение.

## Что внутри
- `design-v3/` — текущий дизайн. `index.html` собирается из `src/partials/` скриптом `build.py`; стили — `assets/css/blocks/`, скрипты — `assets/js/menteya.js` (мозг, карта, галерея, мастер) и `assets/js/motion.js` (движение); `tools/` — замеры плавности.
- `design/`, `design-v2/` — предыдущие варианты.
- `research/` — концепция и анализ конкурентов; `Ментея Финал.html` — исходный макет.

## Сборка после правок
```bash
cd design-v3 && python build.py
```
Скрипт минифицирует CSS и собирает `index.html`; ссылки на файлы получают метку версии, чтобы браузер не брал старое из кеша.

Это прототип: тексты, фото, цены, имена врачей и отзывы — заглушки.
